# Сборка BLACK SAMP APK через GitHub

1. Создайте **пустой** репозиторий на GitHub, например `BLACK-SAMP-Mobile` (не добавляйте README при создании).
2. Загрузите **содержимое папки** `BLACK_SAMP_Mobile_Launcher` в корень репозитория. Включая скрытую папку `.github/workflows`.
3. В GitHub откройте **Actions** → **Build BLACK SAMP Android APK** → **Run workflow** → **Run workflow**.
4. После завершения с зелёной галочкой откройте запуск и в разделе **Artifacts** скачайте `BLACK-SAMP-Mobile-debug-APK`.
5. Распакуйте скачанный ZIP: внутри будет `app-debug.apk`. Передайте APK тестировщику с Android. Телефон может запросить разрешение на установку из выбранного приложения.

Это **тестовый лаунчер**, не GTA SA и не игровой Android-клиент. Кнопки «Установить игру» и «Играть» намеренно отключены. Проверка обновлений потребует настроенного адреса манифеста. APK подписывается автоматически отладочным ключом CI; для релиза потребуется отдельная безопасная подпись.
