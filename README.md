# BLACK SAMP Mobile — Android Launcher (этап 1)

Это **исходный проект лаунчера**, а не готовый APK с GTA и не работающий мобильный SA-MP клиент.

## Сборка
Откройте папку `BLACK_SAMP_Mobile_Launcher` в Android Studio (JDK 17, Android SDK 35). Дождитесь Gradle Sync и выберите **Build → Build APK(s)**.

## Реализовано
- Android Activity в чёрно-золотом стиле BLACK SAMP.
- Кнопка проверки HTTPS-манифеста обновлений.
- Отдельный Android package ID `com.blacksamp.launcher`.
- «Установить» и «Играть» намеренно заблокированы, пока нет проверенного мобильного игрового клиента.

## Подключение обновлений
В `MainActivity.kt` установите `manifestUrl` на собственный HTTPS URL. Минимальный пример JSON: `{"version":"0.1.0"}`. Пока приложение только читает версию — файлы не скачивает.
